## v1.7 多级目录与手机原生感导航

首页以“科目 → 系统/分区 → 章节 → 专题”逐级选择，不再平铺全部章节；只展示所选章节/专题的开始入口。跨科模糊搜索、候选结果、深链接及继续练习保留。

手机底栏固定四项：章节、上一组、下一组、重新做题。章节按钮从左侧展开抽屉，按系统、章节和专题选择，可搜索、点遮罩或关闭按钮退出；背景锁定滚动与焦点，关闭后恢复。切章只改变位置和练习范围，不清空原作答、历史、错题或收藏。

题干与选项区域横滑时当前题随手指移动，松手达阈值切题，短距离或取消手势回弹；边界有阻尼，不越界。竖向滚动、选项点选、拖拽把手、图片操作、多指及系统边缘手势保持独立。按钮切题有轻量进场动效，减少动态效果设置下关闭非必要过渡。

手机在 HTML 到达时即显示加载页，隐藏中间模板；最终样式和初始化完成后再显示做题页。启动失败保留加载提示并提供重试，禁用脚本时说明原因，不露出不能作答的旧界面。电脑原有专题/拖拽布局和六科题库内容、稳定ID、学习记录不变。GitHub Pages 与 ChatGPT Sites 同步发布。

## v1.6 口诀字词解码，移除普通题搬运

首页第六个同级入口内分“人文知识”和“口诀专项”。专项只考口诀字词所指的疾病、药物、物质或分类，例如核受体“李维嘉”：李→类固醇激素、维→维甲酸（活化维A）、嘉→甲状腺激素。按字词新编题干与同类选项，不复制原章节知识题；同一字词对应同一知识的重复题合并。人文55道知识题保留；人文7条口诀拆成8题，五科278条口诀拆成597题。

v1.5 的1,710道五科搬运题与10道旧式人文口诀题退出专项。已有作答、历史与收藏保留在通用错题本的旧题归档，不继承到新的字词题；原五科及55道人文知识题未改。此前的974条是“口诀—普通题关联”，不是逐字拆解完成数：本版另有696条待核定拆法，明确列在 `docs/humanities-audit.json` 的 pending，不用旧题填充，不声称穷尽全部口诀。每题答后展示原句、展开与真实讲义页码，答前不展示辅助解析。

入口：[人文与口诀](https://evansgh-shi.github.io/xizong_xuechengxuanzeti/index.html?course=humanities)。共用快刷、手机吸顶/滑动、桌面整专题、设置和通用错题本。独立存储名 `xuecheng-humanities-drag-v1` 不变；不改写原科记录。人文9页原文与版式核读；争议个案与批注仍列待核，不将褒义措辞或口诀当绝对诊疗/法律规则。原始PDF未上传，两个站点同步发布。

## v1.4 手机紧凑布局与选项区手势

手机端缩减顶部信息、卡片留白和选项间距，按可用高度选择普通或紧凑密度；选项字号不低于 16px，点击区域不低于 44px。20:9 屏幕上的常规短题与不超过 5 项的选项尽量同屏，包括多选确认按钮。超长文字、图片和系统放大字体时保留滚动，不截断知识内容。

按实际排版不超过 4 行的题干吸顶，滚动选项、解析时仍可阅读；超过 4 行的长题干正常滚动。选项文字区域也支持左滑下一题、右滑上一题，横滑不选答案，竖滑保留滚动；拖拽把手、图片缩放、弹窗、多指和屏幕边缘手势不参与切题。电脑样式、五科题目及原有答题/错题/收藏记录保持不变。GitHub Pages 与 ChatGPT Sites 发布同一构建。

## v1.3 模糊搜索与访问统计

首页在五科章节、专题和同组知识标题中跨科检索，支持大小写/全半角归一、常用简称、漏字及少量错字，按相关性排序并显示候选列表与结果卡。候选标明课程、章节和匹配类型，支持方向键、回车、Esc、中文输入法及直接点击；无可靠匹配时明确提示，不凭空编造结果。搜索词只在本地处理，不写入网址或上传。

首页和五科答题页面最底部显示累计访问人次（PV），接入 Vercount 的纯 JSON 计数接口，不执行第三方脚本，不使用 Cookie、访客 ID 或浏览器记录。每次页面加载只发送一次请求，只有不含查询参数/片段的公开页面地址与 `isNewUv:false`；搜索、切题、重做、打开设置不会额外计数。本地/离线预览不发送计数请求。第三方仍会收到基础网络请求，例如 IP 与浏览器默认请求头，因此不承诺第三方完全不产生日志。

统计按域名分开累计，GitHub Pages 的站点级 PV 也可能包含同域名下的其他页面。PV 不是去重访客数，未接入统计的历史访问不补造；服务超时或被拦截显示“暂不可用”，不以本机数字、缓存旧数或虚假零冒充全站数据。服务说明见 https://www.vercount.one/ ，接口使用 https://events.vercount.one/api/v2/log 。

## v1.2 可选自动跳题

设置 → 快刷模式 → 自动跳题，默认关闭，等待时间可选 1/2/3/5 秒（默认 2 秒）。逐题批改后可自动前进；多选仍需先点“确认答案”，不因选中第一项就提交。整专题/分组同屏会先定位后续未批改题，本页结束后沿原导航顺序切组。末题不循环，已批改的历史不会因跳转重复计次。

倒计时可点“留在本题”暂停；手动操作、打开弹窗、重做、切组、切后台或刷新均取消本次跳转。倒计时不存入作答记录，也不会在刷新后补跳。批量提交不触发自动跳转。手机与电脑偏好仍分别保存；题目数据和旧记录不变。GitHub Pages 与 ChatGPT Sites 分别发布同一构建。

## v1.1 界面更新

- 题库首页：按五科、系统、章节选择，支持搜索和直接进入知识专题；也可继续上次练习。

## 更新网页

需要 Node.js，无需安装额外依赖。在仓库根目录执行：

```sh
node scripts/publish.cjs
```

检查更改后提交 `web/` 和 `docs/` 并推送到 `main`。GitHub Pages 使用 `main` 分支的 `/docs` 目录。重建或重新部署不自动增加版本；下一次正式更新时调整 `web/src/release.json`。本仓库的网页源码为 GitHub Pages 发布源；旧 Sites 托管地址不会因推送本仓库自动更新。

题干、选项、答案、题号与内容版本本次均未改动。来源和覆盖范围见 `web/README.md`、`docs/*-coverage.json` 与审计报告。扫描全文不等同于每个边角知识点均已单独设题。

## 记录与使用范围

无账户、无答题上传；作答、错题和收藏只保存在当前浏览器。同一 GitHub Pages 站点的五科可共用错题本，但不能跨设备自动同步。旧 Sites 网页和 GitHub Pages 是不同网址，原网址的浏览器记录不会自动转移；旧站仍可使用。

题库仅用于个人考试复习，不替代临床诊疗、急救指导或病理诊断。讲义原始 PDF 未上传。
