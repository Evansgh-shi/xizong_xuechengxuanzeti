## 交互与记录

五科采用统一的课程—章节—知识专题—同类选项池结构；单多选分区，可重复使用选项。普通上下组与筛选按章节/专题显示顺序遍历，必须完成当前专题最后部分及末页再进入下一专题。
固定底栏持续显示当前课程、章节、专题和部分/分页，含上一组、提交、核对、重做当前题块、下一组。重做仅清除当前显示题块的答案/评分，保留顺序、位置、历史、错题、收藏及其他题块。手机分行保持可点击区域。
鼠标拖动整项；手机拖动把手，文字区保留点选与滚动。同尺寸副本按实际抓取点跟随，原选项仍保留。取消/Esc/框外释放不改作答；单选替换、多选去重。
五科共用错题本，保留独立命名空间。仅改写题重置当前作答与评分并要求复核；原历史、收藏和旧题归档保留，未受影响题的作答不重置。拆池沿用稳定题号，旧选项文字按旧快照展示，不套用新池的同名局部选项编号。记录只在当前浏览器。

## 页面设置

右上角设置支持原分组/整专题同屏与拖拽/ABC字母作答的四种组合。整专题模式各选项卡不混池、不分页，遵守当前题型、难度和错题筛选；上下组改为上下专题。字母与本组选项顺序一致，手机也显示左侧字母；单选替换、多选追加、再点取消，键盘焦点保留。偏好五科共享、刷新保存，不写入课程答题命名空间。
底栏五个核心操作位置保留，另有上一章/下一章；当前章节区域展示下一章名称，边界章节禁用对应按钮。章节切换沿用普通章节导航，会退出当前筛选连练、保留已有作答。
263项设置模式实测通过：四组合、整个专题题集和正反顺序、同名局部选项ID隔离、整专题实际鼠标/触屏拖拽、字母实际可见、精确多选、键盘、重做、跨科偏好和章节切换。
